# reply-ui

`reply.js` draws a compact JSON reply card as themed UI inside an HTML page, for coding agents that show inline pages in chat. Load it pinned to a tag and put the card in a `<script type="application/json" id="ui">` after it: `<script src="https://cdn.jsdelivr.net/gh/olivercederborg/reply-ui@v1.1.2/reply.js"></script>`. A card is `{"ui": [blocks]}`, where each block is one of `outcome`, `delta`, `change`, `decision`, `table`, `checks`, or `flow`; colors and fonts come from the host page's CSS variables (`--foreground`, `--success`, `--font-mono`, and so on), and a block the renderer doesn't know shows as plain text with a `console.error`.
